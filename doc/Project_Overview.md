# 💚 MedAgent AI - Project Overview

## Introduction

MedAgent AI is a **preventive healthcare assistant** that allows users to input their lifestyle and medical information. The system compresses the input using **ScaleDown API**, calculates a **basic risk score**, and provides **preventive recommendations** to maintain a healthier lifestyle.

---

## Objectives

- Allow users to record health and lifestyle data easily.
- Reduce AI processing costs by **optimizing input text** with ScaleDown API.
- Provide **basic risk analysis** for common lifestyle concerns.
- Display **preventive recommendations** according to symptoms detected in the input.

---

## Key Features

1. **User-friendly frontend** using Streamlit.
2. **Compression of medical history** for AI optimization.
3. **Risk score calculation** based on input keywords.
4. **Preventive recommendations** based on health metrics.
5. Display of **compression statistics** (tokens, ratio, latency).
6. Future-ready **semantic similarity computation** using sentence-transformers.

---

## Audience

- Users interested in monitoring personal health and lifestyle.
- Developers looking for a template for AI-assisted preventive healthcare systems.
- Educators and students exploring **text compression and AI optimization workflows**.

---

## Benefits

- Optimizes AI processing cost.
- Provides **quick insights** on health.
- Easy to extend for **LLM-based recommendations** in future.
- Lightweight, simple to run locally using **Python and Streamlit**.
